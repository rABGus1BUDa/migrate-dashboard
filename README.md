# Ambiente

- Interpretador: 3.12.3
- Gerenciador de pacotes: 24.0
- Framework web: 5.0.4


# Dependências

O framework foi instalado pelo gerenciador de pacotes da linguagem, sem nada extra:

`
pip install django
`


# Iniciando o projeto

`
django-admin startproject jankenpopythondjango .
`

Executado na raiz, gera a pasta do projeto com o nome escolhido.

> Repare que a saida pode variar conforme a versao do runtime.
